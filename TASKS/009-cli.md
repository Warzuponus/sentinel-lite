### analyze

- Load config from `--config` or `default_config()`  
- `findings = analyze_path(args.path, config)`  
- Write JSON array to `--output` (default `findings.json`) using `model_dump(mode="json")`  
- Optional `--json-stdout` prints same JSON  
- Print a one-line human summary to stderr or stdout, e.g. `Findings: N` (not tested strictly)
